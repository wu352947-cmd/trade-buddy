# Trade Buddy 第四批 A 轮：模拟盘图上叠加 + 复盘统计 + 手续费滑点

先读 `BATCH4_LOCAL_BRIEF.md`。**只做本轮**，不做自选分组/模板/提醒/回测。不要 commit/push。

## A1. 主图叠加（针对活动图当前品种）
- 持仓成本线：水平线 + 标签（如「成本 123.45 · 100股」）。
- 未成交限价挂单线：买/卖用不同样式，标签含方向、价格、数量。
- 买卖点标记：成交记录在对应 K 线（按成交时间戳/回放时间戳最近一根）上画买入/卖出标记。
- 可在模拟盘面板或图上开关「显示模拟盘标记」。多图下只画在对应品种的图上。回放时只显示不晚于回放进度的成交点。
- 用 KLineChart overlay / 自定义 overlay，不要搞坏现有画线、测距尺。

## A2. 手续费与滑点（模拟盘设置）
- 在模拟盘面板加设置：手续费率（按成交额百分比，可设最低每笔费用，默认例如 0.1% 、最低 0）、滑点（按价格百分比或按最小跳动，选一种清晰实现，默认 0.05%）。
- 市价买入成交价 = 参考价 ×(1+滑点)，卖出 ×(1-滑点)；限价单成交价不得劣于限价（滑点不能让成交价超过限价）。手续费从现金扣除，计入成交记录与已实现盈亏。
- 设置持久化；旧账户数据缺字段时用默认值迁移，不要清空用户已有虚拟账户。
- 仍强制 1 倍、禁止卖空；现金不足（含手续费）时拒单。

## A3. 复盘统计与导出
- 在模拟盘面板加「复盘统计」页：
  - 权益曲线（按每笔成交后或按日记录账户权益；最简单可在每次成交/每次价格刷新时采样写入本地，并至少在每笔成交时记录一次）。用小型 canvas/svg 折线即可。
  - 最大回撤（金额与百分比）、总收益率、已实现盈亏、交易笔数、胜率、盈亏比（平均盈利/平均亏损，按已平仓的回合计算，说明口径）、累计手续费。
- 导出 CSV：成交记录、权益曲线（两个按钮或一个 zip 都行，CSV 优先，UTF-8 带 BOM 便于 Excel 中文）。
- 统计口径写在页面上。
