# Trade Buddy 第四批 B 轮：自定义自选分组 + 工作区模板 + 本地提醒

先读 `BATCH4_LOCAL_BRIEF.md` 与 A 轮成果。**只做本轮**，不做回测（C 轮）。不要大改 A 轮。不要 commit/push。

## B1. 自定义自选分组
- 在右侧自选面板支持：新建分组、改名、删除（需确认）、分组拖动排序、组内品种拖动排序、向分组添加/移除品种（从搜索弹窗或当前品种「加入自选」）。
- 默认 4 个市场分组作为初始数据，用户可改；数据存 localStorage，带版本号，可「恢复默认分组」。
- 拖动用原生 HTML5 drag & drop 或轻量实现即可，不必引入大库（如需小依赖要说明）。

## B2. 工作区模板
- 「模板」菜单（顶栏或右侧）：把当前工作区保存为命名模板：布局（单/2/4 宫格）、各宫格品种、周期、图表类型、指标、画线（世界坐标）、联动开关。
- 模板列表：切换应用、改名、删除、覆盖保存。
- 导入/导出 JSON（单个模板或全部），导入时做 schema 校验与版本兼容，非法文件给出可读错误，不能崩溃。
- 不要把任何密钥或无关隐私写进模板。

## B3. 本地提醒
- 提醒类型：价格上穿 / 下穿某价、涨跌幅达到阈值（相对前收）、均线金叉 / 死叉（可选 MA 快慢周期）、RSI 高于/低于阈值。
- 每条提醒绑定品种与周期；可启用/暂停/删除；可设单次触发或每根 K 线最多触发一次。
- 触发时：页内 toast/通知中心记录；用户授权后可选浏览器 `Notification`（必须用户点击后请求权限）。
- 价格类提醒在主图画提醒水平线。
- 判断数据来源：当前加载的 bars/quote（含已有轮询或刷新）；回放模式下可选择是否按回放价触发（默认不触发，或清楚说明）。
- **界面醒目写明：「提醒只在本页面打开时生效，关闭页面不会推送」。**
- 提醒和触发历史存 localStorage。

## 验收
- `pnpm typecheck` 与 `pnpm build` 通过。
- 无 key 下：能新建分组并拖动排序、刷新后仍在；能保存/切换/导出/导入模板；能建价格提醒并在图上看到提醒线，触发时出现页内通知（可通过把阈值设在当前价附近或手动触发检查来验证）。
