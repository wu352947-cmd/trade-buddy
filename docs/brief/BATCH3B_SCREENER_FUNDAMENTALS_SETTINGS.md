# Trade Buddy 第三批 B 轮：筛选器 + 财务面板 + 设置页

请阅读 `docs/brief/BATCH3_LOCAL_BRIEF.md` 与已完成的 A 轮代码。**只实现本轮**三件事。不要做虚拟模拟盘（C 轮），不要回退或大改 A 轮已能用的多图与回放。不要 git commit / push。

## B1. 选股筛选器

做一个可用的筛选器面板（右侧新标签、顶栏入口打开的宽幅抽屉或独立区域均可，要适合表格；不要只做无法筛选的占位）。

- 数据：现有品种目录 + `/api/symbols` 自选摘要 + 已能获取的 bars/quote（样本、FRED 在线指数、有 key 时的免费行情）。必要时可新增 `/api/screener` 在服务端算好指标，注意缓存，避免把免费档打爆。
- 筛选条件至少包括：市场（美股 / A 股 / 港股 / 期货与指数）、涨跌幅区间、价格区间、成交量（或成交额）下限、均线位置（如现价在 MA20 / MA60 之上或之下；用已有日线计算，样本数据即可）。
- 结果表可排序（涨跌幅、价格、成交量等），显示数据来源/样本徽章。
- 点击一行：把**活动图**切换到该品种（多图布局下不要误改已解除品种联动的其它图）。
- 无 key 时必须能用（基于样本与 FRED）；条件无结果时给出空状态而不是报错。

## B2. 财务数据面板

新的财务面板（右侧标签或品种详情里的「财务」页均可）：

- **美股（无 key 也要可用）**：用 SEC EDGAR 官方 `companyfacts`（或等价官方 XBRL API），带合规 User-Agent（沿用第二批 `SEC_EDGAR_USER_AGENT` 或项目默认）。为目录内美股准备 CIK 映射（至少 AAPL / MSFT / TSLA / AMZN）。展示关键指标与历史：营收、净利润、EPS、总资产、总负债（能拿到的股本/权益也可）。用表格或简单历史柱/折线，注明单位、期间（年报/季报）和来源「SEC EDGAR」。
- 服务端路由如 `/api/fundamentals?symbol=US:AAPL`，做好缓存与失败回退。
- **A 股 / 港股 / 指数**：仅在配置了相应 key（如 Tushare、EODHD）且该源确实提供对应财务数据时接入；否则显示清晰空状态，说明「无 key 时财务数据目前仅支持美股 SEC 公开 companyfacts；可在设置中配置可选 key」。
- 不要爬付费终端或新闻站 HTML。不要把 key 送到前端。

## B3. 设置页

新增 `/settings`（或工作区内完整设置面板，并在顶栏提供入口）。至少包括：

- **数据源状态**：列出 FRED 公开源、公开资讯/日历、SEC EDGAR、Twelve Data、Polygon、Finnhub、EODHD、Tushare、Baostock 等。每项只显示：名称、用途、**已配置 / 未配置**（无需 key 的公开源显示「无需密钥」）、**在线 / 未知或最近失败**（若已有健康检查或可做一次轻量探测；不要泄露任何密钥或 token 片段）。
- **外观**：主题（深/浅）、涨跌配色（绿涨红跌 / 红涨绿跌），与现有顶栏开关同步，并持久化到 localStorage。
- **默认市场**：打开应用时默认自选分组或默认品种所属市场（美股 / A 股 / 港股 / 期货与指数），持久化。
- 再次强调合规：仅研究与虚拟模拟，无实盘。
- 不要在设置页放真实交易、券商、杠杆选项。

## 本轮验收

- `pnpm typecheck` 与 `pnpm build` 通过。
- 无 key 下筛选器能筛出目录品种并跳转图表；美股财务面板能显示 SEC 关键指标或在失败时给出可读错误与重试；A 股/港股财务为空状态说明；设置页能切换主题/配色/默认市场且刷新后仍在，数据源状态无任何密钥文本。
