先读 `BATCH4_LOCAL_BRIEF.md` 与 A/B 轮成果。本轮实现回测沙盒、测试与文档收尾。不要大改 A/B。不要 commit/push。

## C1. 回测引擎（纯函数，放在 `packages/` 新包或 `apps/web/src/lib/backtest/`，便于测试）
- 输入：K 线数组（时间升序）、策略与参数、初始资金、手续费率（含最低费用可选）、滑点、仓位规则（例如全仓/固定比例，均为 1 倍现货）。
- 预设策略：
  - 双均线交叉（快/慢 MA 周期）
  - 布林线（如收盘跌破下轨买、升破中轨或上轨卖，口径写清）
  - RSI 阈值（低于 X 买、高于 Y 卖）
- **严格无未来函数**：第 i 根收盘后计算的信号，只能在第 i+1 根的**开盘价**成交；指标计算只用到 ≤ i 的数据。最后一根产生的信号没有下一根则不成交。
- 1 倍现货：只能空仓买入或持仓卖出；**禁止卖空、禁止杠杆、禁止加仓超出现金**。
- 成交价：买 = 开盘 ×(1+滑点)，卖 = 开盘 ×(1−滑点)；手续费 = 成交额 × 费率（不低于最低费用）。
- 输出：权益曲线（每根 K 线）、买入持有基准曲线（同样第一根后的开盘买入并计手续费与滑点，口径写清）、交易列表（时间、方向、价格、数量、费用、盈亏）、汇总（总收益、年化可选、最大回撤、胜率、盈亏比、交易次数、累计手续费、相对买入持有超额）。

## C2. 单元测试
- 加一个轻量测试运行器（推荐 `vitest`，或 Node 内置 `node:test` + `tsx`），在根 `package.json` 增加 `test` 脚本，`pnpm test` 能跑。
- 至少覆盖：
  1. 无未来函数：构造一段数据，修改第 i+1 根之后的数据不应改变第 i 根及之前的信号与第 i+1 根的成交价判断；或断言成交时间都是信号根的下一根且价格为该根开盘（加滑点）。
  2. 手续费计算：已知价格、数量、费率、最低费用时，扣费与期末现金精确等于预期。
  3. 滑点方向正确；禁止卖空（空仓卖信号被忽略）。
- 测试不要依赖网络。

## C3. 回测 UI
- 入口：底部面板「策略回测」或右侧标签。
- 选择策略、调参数、初始资金、手续费、滑点；对**活动图当前品种与周期**的已加载 bars 运行（回放模式下可选只用回放前缀，或明确说明使用全部已加载数据）。
- 结果：汇总卡片、权益曲线 vs 买入持有对比图、交易列表。
- 在主图上标出回测买卖点（可开关；与模拟盘标记样式区分）。
- 数据是样本时，结果区醒目标注「基于历史样本数据，非实时，仅供学习」及数据区间来源。
- 写明「教学用途，不构成投资建议」。
