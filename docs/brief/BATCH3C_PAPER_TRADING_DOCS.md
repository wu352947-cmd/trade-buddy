## C1. 虚拟资金模拟盘（必须非常明确是假的）

纯前端本地模拟，数据存在 **IndexedDB 或 localStorage**（不要上服务器、不要账号体系）。

界面（底部面板新标签、右侧面板或单独抽屉均可）必须始终可见 **「虚拟资金·模拟」** 徽章或标题，不得出现「实盘」「券商」「融资」「杠杆」字样，代码里也禁止这些能力。

功能：

- 初始虚拟资金可在首次使用时设定（给一个合理默认，如 1,000,000 计价货币，并允许重置模拟账户——重置要确认）。
- **只支持 1 倍现货**：用虚拟现金买入，卖出只能卖已有持仓。禁止卖空、禁止杠杆、禁止保证金、禁止融资融券。Schema / 下单校验层写死 `leverage = 1`，拒绝任何相反参数。
- 订单类型：市价单、限价单（可指定数量；数量必须为正、且买入手数受现金约束、卖出受持仓约束）。
- **撮合**：
  - 非回放：用活动图当前品种的最新可见价格（quote 或最后一根收盘价；若有 high/low 可用于限价触发判断）。
  - 回放中：用回放当前根的价格撮合（市价用该根收盘或开盘，需在 UI 说明规则；限价在该根 high/low 触及后成交）。
  - 未成交限价单保留为挂单，随新行情或回放步进尝试成交。
- 展示：现金、持仓列表（成本、现价、浮动盈亏）、挂单、成交记录。盈亏颜色跟随当前涨跌配色。
- 下单默认针对**活动图当前品种**。切换品种不要弄丢账户数据。
- 刷新页面后账户、持仓、委托、成交仍在。
- 不接任何券商、不发明真实资金字段、不上传订单。
