# Trade Buddy 第三批 A 轮：多图布局 + K 线回放

请阅读 `docs/brief/BATCH3_LOCAL_BRIEF.md` 的总约束，然后**只实现本轮**的两件事。不要做筛选器、财务面板、模拟盘、设置页（那些是 B/C 轮）。不要 git commit / push。

## A1. 多图布局（1 / 2 / 4 宫格）

在顶栏增加布局切换（1 图、左右 2 图、2×2 的 4 图即可；若空间允许可兼做上下 2 图，非必须）。

- 每个宫格是独立的 `KLineChart` 实例，有自己的品种、周期、图表类型（可先共享图表类型）、画线集合。
- 有一个「活动图」高亮（点击某图即激活）。顶栏品种/周期/指标/画线默认作用于活动图。
- **联动开关**（建议放在顶栏或布局菜单里，默认开启）：
  - 品种联动：在已联动的图之间同步品种；某图可单独「解除品种联动」，之后该图品种独立。
  - 周期联动：同上。
  - 十字光标联动：已联动的图按时间戳对齐光标（没有同一时间戳则落到最近一根并标明）。
- 切换布局时尽量保留已有图的品种与状态（1→4 时新宫格给合理默认品种，如自选里的下一个；4→1 时保留活动图）。
- 4 宫格时主图区仍要专业、可读，不要把价格轴或成交量挤没。宽屏 1600×900 是验收分辨率。
- 右侧栏、左侧画线栏、底部栏保持可用；画线画在活动图上。

不要为了多图而重写整个设计系统。优先在 `TerminalWorkspace` 里组合多个 `KLineChartStage`（可按需要给 Stage 增加受控的光标/品种/周期 props 与回调）。

## A2. K 线回放

在主图区底部或底部停靠栏上方做一条不抢空间的回放控制条：

- 选择回放起点（进度条或点击某根 K 线「从这里回放」）。
- 播放、暂停、单步前进、回到起点、结束回放（恢复全部 K 线）。
- 可调速（如 0.5× / 1× / 2× / 5× / 10×，按「每秒推进几根」实现）。
- 回放中图表只渲染到当前回放进度（含该根），均线/MACD/RSI/BOLL/成交量必须按**可见前缀**重算，不要用未来函数。
- 画线使用时间戳+价格世界坐标，回放时保留；测距尺同样。
- 多图时：默认对**活动图**回放；若周期已联动，可用「按时间戳同步其它已联动图」的选项（能做则做，做不到就在 UI 标明仅活动图回放）。
- 回放进度（当前时间戳/索引、是否播放、速率）要以可给后续模拟盘使用的方式暴露（例如 context、props 或一个小的 store 模块），但本轮不必实现下单。
