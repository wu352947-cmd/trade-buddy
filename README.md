# Trade Buddy

**Trade Buddy** 是一款面向个人学习、复盘与虚拟练习的全球行情研究终端（纯本地运行版本，覆盖 **美股、A 股、港股、期货与指数** 四大核心市场）。

> **合规与定位声明**：
> - **仅限研究学习与纯本地虚拟模拟**：本项目严禁任何真实交易、券商 SDK、真实资金划转、融资融券及任何形式杠杆功能（遵循未成年人保护红线）。虚拟模拟盘数据仅保存在本机浏览器中，界面常驻标注「虚拟资金·模拟」，固定 1 倍现货、禁止卖空。
> - **原创品牌**：Trade Buddy 为独立原创品牌与设计系统，与任何商业看盘平台无隶属关系；图表渲染内核采用 Apache 2.0 开源协议的 `KLineChart`。
> - **合法数据源**：不爬取 TradingView 或任何新闻/行情 HTML，不使用非官方 Yahoo 图表接口；界面诚实标注数据来源、延迟属性与区间，不伪装交易所实时流。
> - **非投资建议**：界面展示的全部历史与延迟数据仅供学习研究，不构成任何投资建议。

## 快速本地运行

本版本为**纯本地可运行版**（无需云服务器、无需 Docker、无需数据库、无需登录鉴权，无任何 API Key 即可完整运行）。

### 环境要求

- **Node.js** `>= 20.0.0`（推荐 Node 20 / 22 / 24）
- **pnpm** `>= 9`（或直接使用 `npm`）

### 安装与启动

```bash
# 方式一：使用 pnpm（推荐）
pnpm install
pnpm dev

# 方式二：使用 npm
npm install
npm run dev
```

启动后在浏览器打开 `http://localhost:3000`（看盘工作区，等价路由 `/chart`）或 `http://localhost:3000/settings`（设置页）。

### 类型检查与生产构建

```bash
pnpm typecheck
pnpm build
pnpm start
```

## 核心功能使用说明（含第三批 6 项新增能力）

### 1. 基础五区看盘终端（第一、二批）
- **五区布局**：顶栏、左侧画线工具栏、中央 `KLineChart` 主/副图区、右侧可折叠面板（自选/详情、数据窗口、对象树、财务数据、财经资讯流、宏观与财报日历）、底部可折叠面板（虚拟资金·模拟、研究笔记、数据源与合规声明）。
- **图表与指标**：支持实心 K 线、空心 K 线、美国线 (OHLC)、折线图、面积图；`60m / 1D / 1W / 1M` 周期切换；内置 `MA / EMA / BOLL / VOL / RSI / MACD`。
- **画线与测距尺**：趋势线、水平线、射线、平行通道、矩形、斐波那契回撤、文字标注与 **涨跌幅测距尺（`Alt+M`）** + 磁铁吸附；均支持对象树管理与 `Esc` 取消。

### 2. 多图布局与联动（第三批 A 轮）
- **入口**：顶栏右侧布局菜单，支持 **单图 / 左右 2 图 / 上下 2 图 / 2×2 四宫格**。
- **活动图**：点击任意宫格即设为活动图（蓝色高亮边框），顶栏品种/周期/图表类型/指标、左侧画线工具、筛选器点击与模拟盘下单均默认作用于当前活动图；每个宫格右上角支持一键「单图展开」。
- **全局与单图联动**：
  - 布局菜单内可统一开关 **品种联动、周期联动、十字光标联动**（默认全开）。
  - 多图模式下，每个宫格顶栏均有独立的「品种 / 周期 / 光标」按钮，可单独解除或恢复该图联动；十字光标按时间戳跨图对齐（无相同时间戳时自动落到最近一根并标注）。
  - 切换布局时保留已有宫格状态，展开新宫格时自动填充自选列表中的下一代表品种。

### 3. K 线回放（第三批 A 轮）
- **入口**：点击顶栏 **「回放」** 按钮，图表下方弹出紧凑回放控制条。
- **操作方式**：
  - 点击 **「选起点」** 后在图表上点选任意历史 K 线设为起点，或直接拖动进度条定位。
  - 支持 **播放 / 暂停（快捷键 `Space`）**、**单步前进 1 根**、**回到起点**、**结束回放** 及 **0.5× / 1× / 2× / 5× / 10×** 速率调节（按每秒推进 K 线根数）。
- **零未来函数**：回放期间图表、右侧报价详情及全部技术指标（MA/EMA/BOLL/VOL/RSI/MACD）严格基于可见前缀重算；画线与测距尺使用世界坐标随回放保留。
- **多图回放**：默认对活动图回放；当周期联动开启且存在其它已联动宫格时，可切换 **「同步联动图」** 按当前回放时间戳同步截断其它图。

### 4. 选股筛选器（第三批 B 轮）
- **入口**：点击顶栏 **「筛选器」** 按钮，打开宽幅筛选抽屉（服务端路由 `/api/screener`，带内存缓存防打爆免费配额）。
- **筛选与排序**：支持按 **市场（美股 / A 股 / 港股 / 期货与指数）**、**涨跌幅区间**、**价格区间**、**成交量/成交额下限**、**MA20 / MA60 均线上下位置** 筛选，并按涨跌幅、价格、成交量、成交额、偏离均线幅度与近 1 月表现排序；每行清晰标注数据来源徽章。
- **联动图表**：点击任意结果行会将 **当前活动图** 切换到该品种（多图下遵守单图解除品种联动规则，不误改独立宫格）。

### 5. 财务数据面板（第三批 B 轮）
- **入口**：点击右侧图标栏 **「财务数据」** 图标，或从品种详情卡片一键进入（服务端路由 `/api/fundamentals`）。
- **展示内容**：支持切换 **年报 / 季报**，提供关键财务指标摘要卡、历史趋势柱状图（营收 / 净利润 / 稀释 EPS / 总资产）与明细财务表格（含营收、净利润、稀释 EPS、总资产、总负债、股东权益、同比与利润率/负债率指标），并清晰注明币种单位、报告期间与官方来源链接。

### 6. 虚拟资金模拟盘（第三批 C 轮）
- **入口**：点击底部停靠栏 **「虚拟资金·模拟」** 标签展开（支持「标准高 / 加高」高度切换）。界面标签与面板顶部始终可见 **「虚拟资金·模拟」** 徽章。
- **核心规则**：
  - **纯本地、纯虚拟**：账户现金、持仓、委托挂单与成交记录全部保存在当前浏览器 `localStorage`（键名 `trade-buddy:paper-account:v1`），刷新页面自动恢复，不上传任何服务器，无账号体系，不接入外部接口。
  - **初始资金与重置**：首次使用时可自定义初始虚拟资金（默认 `1,000,000` 计价货币，支持快捷预设）；随时可点击「重置账户」并在二次确认后清空持仓/挂单/成交并重设初始虚拟资金。
  - **严格 1 倍现货、禁止卖空**：买入受可用虚拟现金全额约束（限价买单冻结对应资金），卖出仅可卖出当前已有可用持仓（限价卖单冻结对应数量）；Schema 与校验层写死 `leverage = 1` 与 `allowShort = false`，拒绝任何相反参数。
  - **支持订单类型**：市价单、限价单（数量必须为正数，提供 25% / 50% / 全仓快捷比例）；默认针对当前活动图品种下单，切换品种或窗格不丢失账户数据。
  - **撮合规则**：
    - **非回放模式**：市价单按活动图当前品种最新可见价即时成交；限价单若当前价已满足限价则即时成交，否则保留为挂单，随后续行情更新或新 K 线高低价触及后自动成交。
    - **回放模式**：严格使用当前回放 K 线，不使用未来数据。**市价单按当前回放根收盘价成交**；未成交限价单在后续回放步进/播放的新 K 线中触发（买单 `low ≤ 委托价` 按 `min(open, 委托价)` 成交；卖单 `high ≥ 委托价` 按 `max(open, 委托价)` 成交）。即使折叠底部栏，后台仍会持续撮合并在成交时弹出提示。
  - **展示与配色**：实时展示总虚拟权益、可用/冻结现金、持仓市值、浮动盈亏、已实现盈亏、持仓列表（含一键市价平仓与点击跳转图表）、当前挂单（含撤单）与成交记录；盈亏颜色自动跟随当前涨跌配色（绿涨红跌 / 红涨绿跌）。跨市场品种按单一虚拟计价单位面值 1:1 记账，不计手续费与汇率折算。

### 7. 设置页（第三批 B 轮）
- **入口**：顶栏右侧 **「设置」** 按钮（路由 `/settings`）。
- **功能**：
  - **外观与默认市场**：切换深色/浅色主题、绿涨红跌 (`intl`) / 红涨绿跌 (`cn`)、打开应用时的默认市场分组与首开品种，持久化至浏览器 `localStorage` 并与主工作区实时同步。
  - **数据源配置与在线状态**：展示所有公开源与可选 Key 数据源的名称、用途、配置状态（`无需密钥 / 已配置 / 未配置`）与运行/在线状态，支持点击 **「轻量检测在线状态」** 对免 Key 公开源发起轻量探测；**绝不下发或展示任何 API Key 文本**。

## 无 Key vs 有 Key 能力与限制对照

全部外部请求与环境变量密钥均在 **Next.js 服务端 Route Handler** 中处理，绝不下发前端；内置按源配额限流、429 指数退避与两级内存缓存（Fresh + Stale-If-Error）。

| 功能模块 | 无任何 API Key（零配置开箱可用） | 配置可选个人免费 API Key（`.env.local`） | 真实限制说明 |
|---|---|---|---|
| **K 线与报价** | 15 份内置真实历史样本（覆盖美/A/港/ETF/标普）+ **FRED 免 Key 官方 CSV**（`SP500`、`NASDAQCOM` 在线日线） | `TWELVE_DATA` / `POLYGON`（美股/ETF 60m 与 1D 延迟行情）、`FINNHUB`（美股参考报价）、`EODHD`（美/港股 EOD）、`TUSHARE_TOKEN` 或本地 `ENABLE_BAOSTOCK=true`（A 股日线） | 无 Key 时个股为捆绑历史样本，不伪造实时盘口；离线时 `NASDAQCOM` 展示可读提示而不崩溃 |
| **多图布局与回放** | 全部功能完整可用（基于样本与 FRED 在线数据） | 与在线行情无缝兼容，回放基于当前拉取到的历史序列 | 回放期间指标按可见前缀实时重算 |
| **选股筛选器** | 完整可用，基于内置 14 品种日线（样本 + FRED）服务端计算 MA20/MA60 并缓存 | 有 Key 且命中行情缓存时自动融合最新 EOD/延迟快照 | 筛选范围为本地品种目录，不含全市场数千只股票实时扫描 |
| **财务数据面板** | **美股个股（AAPL/MSFT/TSLA/AMZN）完整可用**：直连官方 **SEC EDGAR `companyfacts`**（年报/季报营收、净利、EPS、资产负债等） | 配置 `TUSHARE_TOKEN` 后解锁 **A 股（茅台/平安/招行）** 合并财务报表 | 港股、指数与 ETF 代理在无对应 Key 时展示清晰空状态，不抓取商业终端 HTML |
| **财经资讯流** | 美股个股直连 **SEC EDGAR 监管公告**；全市场聚合 **美联储 / BLS / SEC 官方 RSS & Atom** | `FINNHUB_API_KEY` / `POLYGON_API_KEY` 补充公司与全市场聚合新闻 | A/港股无免 Key 个股新闻源（可切全市场看宏观官方源） |
| **宏观与财报日历** | 解析 **BLS / FRED 官方发布日程 iCal** 与美股 SEC 财报申报记录 | `FINNHUB_API_KEY` 解锁带「前值 / 预测 / 公布」的全球宏观日历与美股 EPS 财报日历 | 无 Key 官方 iCal 仅含时间与事件名，不含预测/公布值 |
| **虚拟资金模拟盘** | **100% 完整可用**（基于样本/FRED 当前价与回放价撮合，数据存本机浏览器） | 有 Key 时可同步按更新后的延迟/EOD 行情撮合 | 纯本地虚拟练习，1 倍现货、禁止卖空、无手续费/滑点/汇率换算 |
| **设置页** | **100% 完整可用**（外观、配色、默认市场持久化，免 Key 公开源在线探测） | 额外展示各已配置 Key 数据源的布尔配置状态与最近调用健康状态 | 仅展示布尔状态，永不泄露密钥文本 |

### 可选环境变量模板（`.env.local`）

如需启用在线免费数据源，可复制根目录 `.env.example` 为 `apps/web/.env.local`（或根目录 `.env.local`）并按需填写（**切勿提交包含真实密钥的 `.env.local` 到 Git**）：

| 环境变量 | 用途与说明 |
|---|---|
| `TWELVE_DATA_API_KEY` | 美股 / ETF 延迟 `60m` 与 `1D` K 线、延迟报价（免费档限额 8次/分、800次/天） |
| `POLYGON_API_KEY` | 美股 / ETF 近 2 年 `60m` / `1D` K 线、前收报价与新闻 |
| `FINNHUB_API_KEY` | 美股参考报价、公司/全市场新闻、含前值/预测/公布的宏观与财报日历 |
| `EODHD_API_KEY` | 美股 / 港股（`00700/09988/03690`）收盘日线 EOD（免费档 20次/天） |
| `TUSHARE_TOKEN` | A 股（`600519/000001/600036`）收盘日线 EOD 与合并财务报表 |
| `SEC_EDGAR_USER_AGENT` | 可选覆盖 SEC 官方要求的联系信息 User-Agent（已有项目默认值） |
| `ENABLE_PUBLIC_FRED` / `ENABLE_PUBLIC_FEEDS` | 免 Key 官方公开源开关（默认 `true`，离线环境设为 `false` 可零外网请求） |
| `ENABLE_BAOSTOCK` | 可选本地 Python `baostock` 适配器开关（默认 `false`，需本机预装 Python 与 `baostock`） |
