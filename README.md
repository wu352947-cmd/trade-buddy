# Trade Buddy

A TradingView-style global market research terminal (web-first, PWA), focused on US stocks, China A-shares, Hong Kong stocks, and futures/indices.

**Research and simulation only.** No real trading, no brokerage integration, no real leverage.

- Product & technical plan (v2): [`docs/plan/PLAN.md`](docs/plan/PLAN.md)
- Planning brief and confirmed decisions: [`docs/brief/`](docs/brief/)
- UI reference screenshots used for layout/interaction study: [`docs/ui-refs/`](docs/ui-refs/) (see `MANIFEST.md`)

Trade Buddy uses its own original brand and design system and is not affiliated with TradingView.

Status: planning (v2). Implementation starts with Batch 1 in the plan.
