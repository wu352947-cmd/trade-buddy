# Trade Buddy

**Trade Buddy** 是一款面向个人学习、复盘与虚拟练习的全球行情研究终端（纯本地运行版本，覆盖 **美股、A 股、港股、期货与指数** 四大核心市场）。

> **合规与定位声明**：
> - **仅限研究学习与纯本地虚拟模拟**：本项目严禁任何真实交易、券商 SDK、真实资金划转、融资融券及任何形式杠杆功能（遵循未成年人保护红线）。虚拟模拟盘与教学回测沙盒均为固定 **1 倍现货、禁止卖空、禁止杠杆**，数据仅保存在本机浏览器中，界面常驻标注「虚拟资金·模拟」或「教学用途，不构成投资建议」。
> - **原创品牌**：Trade Buddy 为独立原创品牌与设计系统，与任何商业看盘平台无隶属关系；图表渲染内核采用 Apache 2.0 开源协议的 `KLineChart`。
> - **合法数据源**：不爬取 TradingView 或任何新闻/行情 HTML，不使用非官方 Yahoo 图表接口；界面诚实标注数据来源、延迟属性与区间，不伪装交易所实时流。
> - **非投资建议**：界面展示的全部历史与延迟数据及回测统计仅供学习研究，不构成任何投资建议。

## 快速本地运行

本版本为**纯本地可运行版**（无需云服务器、无需 Docker、无需数据库、无需登录鉴权，无任何 API Key 即可完整运行）。

### 环境要求

- **Node.js** `>= 20.0.0`（推荐 Node 22 / 24；运行 `pnpm test` 原生 TypeScript 单元测试推荐 Node 24）
- **pnpm** `>= 9`（或直接使用 `npm`）

### 安装与启动

```bash
# 方式一：使用 pnpm（推荐）
pnpm install
pnpm dev

# 方式二：使用 npm
npm install
npm run dev
```

启动后在浏览器打开 `http://localhost:3000`（看盘工作区，等价路由 `/chart`）或 `http://localhost:3000/settings`（设置页）。

### 类型检查、单元测试与生产构建

```bash
pnpm typecheck   # TypeScript 严格类型检查
pnpm test        # 运行纯函数回测引擎单元测试（零网络依赖，覆盖无未来函数/手续费/滑点/禁卖空）
pnpm build       # Next.js 生产构建
pnpm start       # 启动生产构建服务
```

## 核心功能使用说明（第一批至第四批全量能力）

### 1. 基础五区看盘终端（第一、二批）
- **五区布局**：顶栏、左侧画线工具栏、中央 `KLineChart` 主/副图区、右侧可折叠面板（自选/详情、本地提醒、数据窗口、对象树、财务数据、财经资讯流、宏观与财报日历）、底部可折叠面板（虚拟资金·模拟、策略回测、研究笔记、数据源与合规声明）。
- **图表与指标**：支持实心 K 线、空心 K 线、美国线 (OHLC)、折线图、面积图；`60m / 1D / 1W / 1M` 周期切换；内置 `MA / EMA / BOLL / VOL / RSI / MACD`。
- **画线与测距尺**：趋势线、水平线、射线、平行通道、矩形、斐波那契回撤、文字标注与 **涨跌幅测距尺（`Alt+M`）** + 磁铁吸附；均支持对象树管理与 `Esc` 取消。

### 2. 多图布局与联动（第三批 A 轮）
- **入口**：顶栏右侧布局菜单，支持 **单图 / 左右 2 图 / 上下 2 图 / 2×2 四宫格**。
- **活动图**：点击任意宫格即设为活动图（蓝色高亮边框），顶栏品种/周期/图表类型/指标、左侧画线工具、筛选器点击、模拟盘下单与策略回测均默认作用于当前活动图；每个宫格右上角支持一键「单图展开」。
- **全局与单图联动**：
  - 布局菜单内可统一开关 **品种联动、周期联动、十字光标联动**（默认全开）。
  - 多图模式下，每个宫格顶栏均有独立的「品种 / 周期 / 光标」按钮，可单独解除或恢复该图联动；十字光标按时间戳跨图对齐（无相同时间戳时自动落到最近一根并标注）。

### 3. K 线回放（第三批 A 轮）
- **入口**：点击顶栏 **「回放」** 按钮，图表下方弹出紧凑回放控制条。
- **操作方式**：支持 **选起点**、拖动进度条、**播放 / 暂停（`Space`）**、**单步前进 1 根**、**回到起点**、**结束回放** 及 **0.5× / 1× / 2× / 5× / 10×** 速率调节。
- **零未来函数**：回放期间图表、右侧报价详情及全部技术指标严格基于可见前缀重算；多图周期联动开启时可勾选 **「同步联动图」**。

### 4. 选股筛选器与财务数据面板（第三批 B 轮）
- **筛选器**：点击顶栏 **「筛选器」** 按钮，支持按市场、涨跌幅、价格、成交量/额及 `MA20 / MA60` 位置筛选与多列排序，点击结果行直接联动活动图。
- **财务数据**：点击右侧导轨 **「财务数据」** 图标，美股免 Key 直连 **SEC EDGAR `companyfacts`** 展示年报/季报核心财报指标、趋势柱状图与明细表；配置 `TUSHARE_TOKEN` 后解锁 A 股财报。

### 5. 虚拟资金模拟盘（第三批 C 轮 + 第四批 A 轮增强）
- **入口**：点击底部停靠栏 **「虚拟资金·模拟」** 标签展开（支持「标准高 / 加高」切换）。界面始终可见 **「虚拟资金·模拟」** 徽章。
- **核心规则**：
  - **纯本地、纯虚拟、1 倍现货、禁止卖空**：账户保存于 `localStorage`（`trade-buddy:paper-account:v1`）；Schema 与引擎写死 `leverage = 1` 与 `allowShort = false`，现金不足（含预估手续费）或超持仓卖出均直接拒单。
  - **支持订单类型**：市价单、限价单（支持 25% / 50% / 全仓快捷比例）；兼容非回放当前价撮合与回放逐根无未来函数撮合。
- **第四批 A 轮新增能力**：
  - **主图叠加（可开关）**：在对应品种主图绘制 **持仓成本水平线**（含均价与持仓股数）、**未成交限价挂单线**（区分买卖虚线样式与价格/数量标签）、以及 **买卖点三角标记**；多图下仅画在对应品种的图上；回放模式下严格隐藏晚于当前回放进度的成交点。支持在模拟盘面板或图表左上角快捷按钮开关。
  - **手续费与滑点设置**：支持自定义 **手续费率（默认 `0.1%`）**、**每笔最低费用（默认 `0`）**、**滑点比例（默认 `0.05%`）**，持久化保存且自动兼容旧版账户数据迁移：
    - 市价买入成交价 = `参考价 × (1 + 滑点%)`；市价卖出成交价 = `参考价 × (1 - 滑点%)`。
    - 限价单成交价不得劣于委托限价（买单 `min(限价, 参考价×(1+滑点%))`，卖单 `max(限价, 参考价×(1-滑点%))`）。
    - 手续费 = `max(成交额 × 费率%, 最低费用)`，从可用现金扣除，计入成交记录与已实现盈亏。
  - **复盘统计与 CSV 导出**：新增「复盘统计」子页，内置 SVG **虚拟权益曲线**（含悬停读数与回撤显示），展示总收益率、已实现/浮动盈亏、最大回撤（金额与百分比）、累计手续费、交易笔数、**胜率**与**盈亏比**（按同一品种从空仓建仓至全部清仓的**完整已平仓回合**计算，盈亏比 = 平均盈利回合净盈亏 ÷ 平均亏损回合净亏损绝对值）。支持一键下载 **成交记录 CSV** 与 **权益曲线 CSV**（UTF-8 带 BOM，Excel 直接打开中文不乱码）。

### 6. 自定义自选分组、工作区模板与本地提醒（第四批 B 轮）
- **自定义自选分组（B1）**：
  - 右侧「自选/详情」面板支持 **新建分组、重命名、确认删除、原生拖拽排序分组、组内/跨组拖拽排序品种、向分组添加/移除品种**（亦可在品种搜索弹窗中直接勾选所属分组）。
  - 初始内置 4 个市场默认分组，存 `localStorage`（`trade-buddy:watchlist-groups:v1`），随时可一键「恢复默认分组」。
- **工作区模板（B2）**：
  - 顶栏 **「模板」** 菜单可将当前工作区保存为命名模板，完整快照：**多图布局模式、活动宫格、各宫格品种/周期/图表类型/指标/世界坐标画线（含文字标注与测距尺）、全局与单图联动开关**。
  - 支持模板 **切换应用、覆盖保存、重命名、删除**，以及 **单模板 / 全部模板 JSON 导入导出**。导入时进行严格 Zod Schema 与 `schemaVersion` 校验，非法文件给出可读错误提示而不崩溃；**绝不写入任何密钥或隐私信息**。
  - **模板 JSON 格式说明**：
    - 单个模板导出包裹：`{ "app": "trade-buddy", "kind": "workspace_template", "schemaVersion": 1, "exportedAt": "...", "template": { ... } }`
    - 批量模板导出包裹：`{ "app": "trade-buddy", "kind": "workspace_templates", "schemaVersion": 1, "exportedAt": "...", "templates": [ ... ] }`
    - 核心 `template` 字段包含：`id`、`name`、`schemaVersion: 1`、`layout`（`single | split_h | split_v | grid_2x2`）、`activePaneId`、`syncConfig`（`symbol/interval/crosshair`）、`panes`（1~4 个宫格的 `paneId/initialized/symbolId/interval/chartType/activeIndicators/drawings/links`）。
- **本地提醒（B3）**：
  - 右侧图标栏 **「本地提醒」** 面板（铃铛图标）支持 9 类条件：**价格上穿/下穿**、**涨/跌幅及绝对波动达到阈值（相对前收）**、**均线金叉/死叉（可自定义快慢 MA 周期）**、**RSI 高于/低于阈值（可自定义周期）**。
  - 每条提醒绑定品种与周期，支持启用/暂停/删除、设置触发频率（**单次触发** 或 **每根 K 线最多一次**），并支持一键「立即检查全部提醒」。
  - 触发时弹出页内通知 Toast 并记入通知历史；用户手动点击授权后可选开启浏览器原生 `Notification`；价格类提醒会在对应品种主图绘制水平虚线提醒线（可开关）；回放模式下默认不触发（可在设置中手动勾选开启）。
  - **重要说明**：界面多处醒目标注 **「提醒只在本页面打开时生效，关闭页面不会推送」**；规则与触发历史存 `localStorage`（`trade-buddy:local-alerts:v1`）。

### 7. 教学回测沙盒（第四批 C 轮）
- **入口**：点击底部停靠栏 **「策略回测」** 标签展开（支持「标准高 / 加高」切换），针对 **当前活动图的品种与周期** 已加载 K 线运行（回放模式下可勾选「仅用回放前缀」或使用全部已加载数据）。
- **预设教学策略与可调参数**：
  - **双均线交叉（MA）**：自定义快线 / 慢线 SMA 周期（默认 `5 / 20`）；快线上穿慢线金叉产生买信号，下穿死叉产生卖信号。
  - **布林带（BOLL）**：自定义周期（默认 `20`）、标准差倍数（默认 `2σ`，总体标准差）及卖出目标（默认升破**中轨**卖，可切升破**上轨**卖）；收盘跌破下轨产生买信号。
  - **RSI 阈值**：自定义 Wilder RSI 周期（默认 `14`）、超卖买入阈值（默认 `< 30`）与超买卖出阈值（默认 `> 70`）。
- **严格回测规则（教学口径）**：
  - **严格无未来函数**：第 `i` 根 K 线收盘后，所有指标与信号仅使用索引 `≤ i` 的历史数据计算；信号严格在第 `i + 1` 根 K 线的 **开盘价** 成交；最后一根产生的信号因无下一根而不成交。
  - **1 倍现货、禁止卖空与杠杆**：仅允许空仓买入、持仓全额卖出；空仓时的卖出信号直接忽略；支持全仓（100%）或固定比例建仓（上限 100%），严禁透支现金或杠杆。
  - **手续费与滑点**：买价 = `开盘价 × (1 + 滑点%)`，卖价 = `开盘价 × (1 − 滑点%)`；每笔手续费 = `max(成交额 × 费率%, 最低费用)`。
  - **买入持有基准**：在第 2 根 K 线（索引 `1`）开盘时以 1 倍全仓买入并持有至期末，套用完全相同的滑点与手续费模型，确保公平对比。
- **可视化结果与主图标记**：
  - 汇总卡片：策略总收益、买入持有基准收益、超额收益、最大回撤、年化收益（参考）、胜率、盈亏比、交易次数与累计手续费。
  - 双线权益对比图（策略实线 vs 买入持有虚线，支持悬停查看逐日权益、超额与回撤）。
  - 交易明细表（信号时间、成交时间[下一根开盘]、开盘价、成交价、数量、手续费、回合净盈亏与触发原因）及一键导出 CSV。
  - **主图回测买卖点（可开关）**：以 **菱形标记（天蓝 `测·买` / 紫红 `测·卖`）** 绘于主图对应成交 K 线，与模拟盘三角形标记清晰区分。
  - 当活动图使用历史样本数据时，结果区顶部醒目标注 **「⚠ 基于历史样本数据，非实时，仅供学习」**、来源与区间，并常驻标注 **「教学用途，不构成投资建议」**。

### 8. 设置页（第三批 B 轮）
- **入口**：顶栏右侧 **「设置」** 按钮（路由 `/settings`）。支持切换深浅主题、绿涨红跌 / 红涨绿跌配色、默认市场分组（持久化至 `localStorage` 并跨标签页同步），以及查看数据源布尔配置状态与免 Key 公开源在线探测（**绝不下发或展示任何 API Key 文本**）。

## 无 Key vs 有 Key 能力与限制对照

全部外部请求与环境变量密钥均在 **Next.js 服务端 Route Handler** 中处理，绝不下发前端；内置按源配额限流、429 指数退避与两级内存缓存（Fresh + Stale-If-Error）。

| 功能模块 | 无任何 API Key（零配置开箱可用） | 配置可选个人免费 API Key（`.env.local`） | 真实限制说明 |
|---|---|---|---|
| **K 线与报价** | 15 份内置真实历史样本（美/A/港/ETF/标普）+ **FRED 免 Key 官方 CSV**（`SP500`、`NASDAQCOM`） | `TWELVE_DATA` / `POLYGON`、`FINNHUB`、`EODHD`、`TUSHARE_TOKEN` 或 `ENABLE_BAOSTOCK=true` | 无 Key 时个股为捆绑历史样本，不伪造实时盘口 |
| **多图布局与回放** | 全部功能完整可用 | 与在线行情无缝兼容 | 回放期间指标按可见前缀实时重算 |
| **选股筛选器** | 完整可用（基于目录 14 品种日线计算 MA20/MA60） | 自动融合缓存中的最新 EOD/延迟快照 | 仅覆盖本地品种目录，非全市场数千股扫描 |
| **财务数据面板** | 美股个股直连 **SEC EDGAR `companyfacts`** | `TUSHARE_TOKEN` 解锁 A 股财报 | 港股、指数与 ETF 无免 Key 财报源 |
| **财经资讯与日历** | SEC EDGAR 公告、美联储/BLS/SEC 官方 RSS & iCal | `FINNHUB_API_KEY` / `POLYGON_API_KEY` 补充新闻与前值/预测/公布日历 | 无 Key 官方 iCal 不含预测/公布数值 |
| **虚拟资金模拟盘** | **100% 完整可用**（含图上叠加、手续费/滑点、复盘统计与 CSV 导出） | 可按更新后的在线行情撮合 | 纯本地 1 倍现货无卖空，跨市场面值 1:1 记账 |
| **自选分组 / 模板 / 本地提醒** | **100% 完整可用**（纯本地 `localStorage` + JSON 导入导出） | 在线行情刷新时同步评估提醒条件 | 提醒仅在本页面打开时生效，无服务端后台推送 |
| **教学回测沙盒** | **100% 完整可用**（含 AAPL 等内置历史样本、对比曲线、交易表与主图标记） | 可直接对拉取到的在线历史 K 线运行回测 | 1 倍现货无卖空无杠杆，不考虑盘口深度/分红除权/融资利息 |

## 已知限制

1. **纯本地存储**：模拟盘账户、自选分组、工作区模板、本地提醒与研究笔记均保存在当前浏览器 `localStorage`，不上传服务器，清理站点数据或更换浏览器不会自动同步（模板与模拟盘记录支持本地 JSON / CSV 导出备份）。
2. **本地提醒触发条件**：所有提醒评估在浏览器前端执行，**仅在页面保持打开时生效，关闭标签页或浏览器后不会后台推送**；若未拉取过某品种对应周期的 K 线，需打开该品种或点击「立即检查全部提醒」按需拉取评估。
3. **跨市场记账与回测简化假设**：模拟盘与回测均采用单一虚拟计价单位 1:1 记账，不含汇率换算、印花税、过户费、分红再投资、停牌涨跌停流动性限制及盘口深度冲击模型。
4. **数据源免费配额与样本延迟**：无 API Key 时个股行情为捆绑真实历史样本（界面已醒目标注来源与时间区间），仅用于图表学习、复盘与策略教学验证，不可作为真实交易依据。
